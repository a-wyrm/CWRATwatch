About The CWRAT Adoption Map

This map, largely inspired by ACLU's reporting, highlights the growing adoption of child welfare risk assessment tools (CWRAT) across the United States. These tools use predictive modeling to determine the likelihood of child welfare concerns for families before and after birth. They are known to discriminate against black and brown, disabled, and poor parents.

Like criminal justice predictive modeling, these technologies use proxy predictors deeply rooted in societal prejudices to proxy for maltreatment. Some of these include public benefit usage, prior mental health history (for parent and child), or previous incarceration status. No matter what fine-tuning is done to "mitigate" these concerns, these biases are deeply embedded into the data. Some of these tools are designed by foreign institutions without the input of US social workers.

The US government has recently announced a 6 million dollar pilot program to push more of these predictive models. In an effort to combat these harms, I have sent FOIA requests to over x counties who have historically used, or are currently using, predictive modeling algorithms.

The data includes each state and territory that uses these tools, as well as model predictor variables, cost of development, security protocol for data storage, and other information. FOIA files are available to download.

The CWRAT Adoption Map is an open-source project.

This project was inspired by reporting done by the ACLU and ICEwatch by Lockdown Systems. Please support their work.
